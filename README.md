# Sistema de Gestión de Exportación de Flores (SGEF)

El **Sistema de Gestión de Exportación de Flores (SGEF)** es una
aplicación desarrollada como proyecto académico y profesional, cuyo
objetivo es **optimizar y digitalizar los procesos de gestión de
usuarios, empresas clientes y operaciones relacionadas con la
exportación de flores**.

## 🚀 Objetivo del Proyecto

El propósito del SGEF es proporcionar un sistema modular que facilite: -
El registro, consulta y administración de usuarios. - El registro y
validación de empresas clientes de distintos países. - La estructuración
de requisitos funcionales siguiendo estándares profesionales. - La
implementación de casos de prueba reales con validaciones complejas. -
La construcción de un módulo totalmente funcional basado en
especificaciones empresariales.

## 📌 Características Principales

### 🔐 Gestión de Usuarios

-   Registro de nuevos usuarios.
-   Validación de campos según reglas definidas en el ERS.
-   Edición, consulta y eliminación.
-   Trazabilidad y estructura orientada por requisitos funcionales.

### 🏷️ Registro de Empresas Cliente

-   Validación avanzada de identificadores empresariales según país.
-   Validación de nombre, dirección, correo y teléfono.
-   Mensajes de salida detallados: éxito o lista de errores.


### 📄 Documentación Completa

-   Documentación formal del sistema en formato ERS.
-   Redacción profesional de requisitos siguiendo estándares
    empresariales.
-   Desarrollo de casos de prueba completos.
